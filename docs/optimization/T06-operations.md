# 持久任务使用与恢复

前后端需配对升级。后端仍为单进程，SQLite v5 保存任务、步骤和资源锁，两个任务 worker 共用全局 5 个 AWS 调用预算。启动时迁移失败会停止启动；迁移备份与恢复沿用 T01 的包含 WAL 的一致性备份、SHA256 和完整性检查。

## 提交与查看

建机、开关机、重启、换 IP、删除及流量同步提交 `/api/v2/tasks`，必须明确 `credential_id` 并提供 `Idempotency-Key`。202 只确认任务已持久接受，不表示 AWS 已执行完成。同用户同 key 和同请求找回原 task；改请求却复用同 key 返回409。

任务中心展示持久步骤、结果及错误。刷新后可通过任务 URL 或列表找回，未解决任务优先，历史可分批浏览。提交响应丢失时浏览器仅保存随机提交标识与资源槽，不保存密码、userData 或请求体。可在任务中心按原标识找回；重新输入请求时继续使用原 key，后端判断是否同一请求。409 不会被转换成旧任务的成功提交。

旧写接口走相同任务执行器；一秒等待窗口内完成则保留原响应字段，超时返回202和task_id。旧流量同步返回每个账号的任务列表。定时流量采集只提交持久任务，自动关机是同一账号任务里的步骤，与手动资源变更互斥。

## 状态与恢复操作

| 状态 | 含义与操作 |
|---|---|
| queued | 已持久接受；只有从未执行的任务可取消 |
| running | worker 正在执行，不能取消 |
| succeeded | 所有要求步骤已确认完成 |
| failed | 明确失败或补偿完成；结果说明决定是否仍有已创建资源 |
| partial | 所有副作用已知且无未决补偿，例如实例已创建但 IP 绑定失败且新 IP 已释放；查看结果后可另交换 IP 任务 |
| reconciliation_required | 写结果不明、身份变化或剩余步骤未完成，继续保留账号/资源锁 |
| cancelled | 从未开始的任务已取消 |
| resolved | 所有者显式决定自行处理并解除锁；AWS 结果未确认，不表示系统成功核对 |

待核对任务先执行“只读核对”。Operation ID、task marker、持久 ARN 和实际状态能证明结果时才把未知步骤转为已知；重启不会自动重放不明写请求。所有未知步骤已核对后，点击“继续剩余步骤”，跳过已完成写入，仅重试允许的明确失败步骤。Reboot 前后 running 不能证明本次重启，缺少 Operation 证据时仍待核对。

原凭证/代理版本变化后不借用新凭证继续旧任务。尚未产生副作用的任务明确 failed 并释放锁；已有副作用时保留锁。若无法用原凭证核对，所有者可在自行核实 AWS 资源后选择“人工决议”，确认完整任务 ID。系统不补写 AWS 成功、不撤销原请求、不重放写入，保留未知步骤与 `aws_outcome_confirmed=false`。未知请求仍可能稍后生效，决议后的处理由所有者承担。

同账号多 Key 共享资源锁；流量同步持有账号锁。用户/凭证仍有未解决任务时不允许删除。常规终态保留30天，在启动及现有采集调度周期清理；未解决及 `resolved` 未知事实记录继续保留。进程长时间运行时，调度也回收过期 worker 租约；有步骤的任务进入核对，不自动继续副作用。

## AWS 边界

所有任务子调用使用绑定版本的凭证/代理。真实 SDK 传输前（取得并发槽之后）再检查版本与代理，不允许代理失败后直连。写操作关闭 SDK 自动重试，先持久化意图再调用。响应丢失先核对，`Started` 不等于成功。

Static IP 没有 tags，分配使用预先记录的确定名、缺席预读、createdAt 和后续 ARN；绑定/释放/补偿核对既定 ARN。新绑定确认前不释放旧 IP。删除只释放删除前真实 `attachedTo` 清单，实例消失后才清理，绝不使用名称前缀认领。

AWS 写 API 按名称操作且没有条件 ARN 参数：已经读到的身份变化会阻止提交，但 AWS 读写之间最后瞬间的外部替换无法由本应用原子排除。未调用真实 AWS 验证；验证使用状态化 SDK double、实际 factory/limiter 和 transport 禁止器。
