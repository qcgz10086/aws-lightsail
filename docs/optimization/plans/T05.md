# T05 前端请求缓存、竞态保护与按需加载

计划 V1.0（2026-11-17）；BASE 为独立通过的 T04 第五次返修交付 `234d1a91e8e24934d2730b4a5a88c8205ac1f649`，产品代码源 `54fa12b0b55b00b43341d99b768f7769b002a9db`。本任务在独立 T05 worktree 实施。

## 范围

1. 在现有 Axios/React 架构加入内存共享 GET 缓存和同 key 请求合并；键包含登录用户作用域、URL 和规范化 query 参数。仅缓存白名单只读接口，设置有界 TTL；登录用户切换/退出清除内存结果。缓存 tag 同时带域 tag 与 credential/region 组合范围 tag，使局部变更精确失效且涵盖聚合视图；调用方补充 tag 时与默认域 tag 合并。凭证、实例写入、流量同步、账单手动记录等成功写入，按数据 tag 失效关联查询缓存；错误和取消结果不缓存。
2. 页面效果副作用的 GET 可被调用方取消；共享请求有订阅者计数，最后一个消费者取消时 abort HTTP 请求。选择账号/区域、路由切换和组件卸载时取消旧工作，并以代次校验拒绝旧响应写入 state。错误 abort 不弹用户提示。
3. Dashboard、Instances、Traffic、Billing、Credentials、CreateInstance 与 InstanceDetail 共用凭证/目录/汇总等查询结果，减少同屏和跨页重复请求。刷新采用数据域/当前账号/当前区域，避免为局部刷新清除或重载无关界面状态；实例页增加可选区域过滤和对应区域刷新。
4. 用 `React.lazy`/`Suspense` 对业务路由按页分包，登录和初始 shell 不导入尚未访问的重页面；按实际 Vite 产物记录主包及各 chunk 大小，检查原有大 chunk 提示是否改善。
5. 保留 Python/TypeScript、React、Ant Design、Axios、Vite，无新运行时/构建依赖；不修改后端、API contract、Nginx/部署结构，不调用真实 AWS。

## 验收与验证

- 用固定可重复的前端 cache 单元探针覆盖同 key 去重、query/用户隔离、TTL、按 tag 失效、取消最后消费者、共享消费者中单个取消不影响另一方、错误不缓存、scope 切换立即拒绝旧订阅、取消后新订阅不复用 aborted loader。取消/失效不得依赖 transport 配合 abort；被失效订阅自行立即以 `AbortError` 结束。
- `tsc --noEmit` 与 Vite production build 通过；在可用浏览器环境进行切页/切账号/切区域和请求竞态验证，记录请求次数、主包/chunk 体积及未验证边界。无浏览器 E2E 环境时不虚报通过。
- 实施前比较 BASE 的同一 build 命令及静态页面/依赖入口；产物需要列表与 hash。前端按需加载至少使首载 JS 明显低于 BASE；其余镜像、真实浏览器性能、CPU/内存仍交 T07/最终集成实测。
- 每项产品代码和测试固定 HEAD 后，将本计划、交接、命令与结果、性能证据、限制保存到 `docs/optimization/handoffs/T05.md` 和 `docs/optimization/evidence/T05-<HEAD>/`；只交独立审计结论，不自我放行 T06。
