## 实施内容

前端加入用户/URL/query 归一化的有界共享 GET 缓存、TTL、同 key 合并、取消订阅和 tag 失效。组合 credential/region scope 使单范围刷新命中对应范围及聚合视图，页面显式 tag 与默认 tag 合并。登录会话使用 generation 隔离认证响应；业务页以 AbortSignal、请求代次及最新 load 引用阻止旧响应覆盖。业务路由使用 lazy/Suspense 分包。Dashboard 与 Instances 共享实例快照，Dashboard 保留每 credential/region snapshot 状态：stale 数据显示最近成功时间和错误，冷权限/目录失败不显示健康的零实例。建机表单在 credential/region 切换时同步废弃旧目录和选择，提交 handler 再核实 credential、region、region catalog scope、bundle/blueprint 成员和 blueprint platform；status、enable、poll 回调由 credential、region、catalog generation 限定。

`docs/optimization/plans/V1.0.md` 同时加严 T06 验收：建机、IP 变更/绑定/释放、删除清理、区域/目录查询和同步的各 AWS 子步骤都要复用该凭证代理；覆盖显式与自动选择可用区，并在 fake client/transport 下逐步断言代理参数，代理失败不能直连回退。这项是 T06 实施与最终集成必须修复、必须验收的继承后端问题，不妨碍 T06 在 T05 交付独立审计通过后开始；未关闭前不得作最终项目验收。

本任务未修改 Python/backend、deployment 或依赖版本，未增加运行时依赖。`BASE..产品 HEAD` 不含 `backend`、`tools` 代码改动，因此没有重跑 T04 的后端套件；这不等于后端或最终集成通过，最终集成需按计划重新执行后端/代理回归。没有真实 AWS 请求，也没有合并、推送、发布、部署或关机。
