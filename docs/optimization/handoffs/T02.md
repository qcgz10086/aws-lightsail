## 修改范围

1. 凭证创建、更新、手动校验及兼容 PUT 持久化 STS `account_id`。未知身份不参与确认账号归并；最后确认账号只作为保守暂停依据。换密钥清除旧身份并重新校验；不猜测账号，不搬旧配置。
2. 所有 boto3 客户端经过共同构造入口，显式凭证与代理覆盖 Lightsail、Service Quotas、Account、STS、Billing、CE。损坏/无效代理停止；省略代理字段与明确清除不同。明确直连忽略进程代理环境，显式代理不受 `NO_PROXY=*` 绕过。
3. 同一面板用户与确认账号扫描一次；具体操作保留 `credential_id`。流量以观测时账号快照保存，换账号不会污染历史；未知历史可见但不计地区确认总额。实例列表和策略计算使用批量数据库读取。
4. 自动关机冲突包含显式开/关和启用阈值不同。保存原设置并暂停全部竞争策略；STS 故障、切默认 Key、单条 PATCH 变成相同值均不自动解锁。冲突详情返回全部当前用户策略与内容指纹；只有身份均已确认、配置一致、完整竞争 ID 和指纹都匹配时才明确解除。前端实例列表表单以原始策略初始化，`onValuesChange` 记录实际编辑字段；只读详情页标记旧账号配置未生效。
5. 数据库 v2 为追加台账：凭证身份、策略绑定/冲突和流量账号快照。继承 T01 一致性备份、事务回滚、失败停止启动；旧策略 false 仍为明确覆盖。流量唯一约束增加账号快照，只替换准确识别的 T01 旧唯一键，其他可支持显式索引保留，未知定制语义拒绝。
