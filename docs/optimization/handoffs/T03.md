## 历史精度限制

SQLite REAL 已失去原始十进制输入精度，迁移无法恢复。`apply_v3` 用 `Decimal(str(legacy_float))` 记录 Python 可见的最短十进制近似值，按 512 行分批，不采用 `Decimal(float)` 展开二进制尾数，也不宣称精确复原。迁移记录 `amount_precision=legacy_float`；API 的 `precision_note` 和 UI“历史浮点近似”说明限制。新建记录显式 `exact_decimal`，金额文本为权威值；旧 Float 仅用于旧数据库/客户端兼容。两类手动金额均不作为逐笔剩余推算依据。
